# Sample Generated Flow

1. Parse the source into sections, bullets, paragraphs, and code blocks.
2. Infer `category`, `audience`, `purpose`, `core_message`, and `technical_depth`.
3. Merge redundant sections and compress verbose text into presentation-grade points.
4. Turn technical material into `process` or `architecture` slide blueprints when appropriate.
5. Select category-aware assets only for slides that benefit from them.
6. Run the quality loop to reduce weak text-heavy slides and vary layout rhythm.
7. Render a real `.pptx` with `PptxGenJS` and emit `deck_source.js` for rebuild traceability.
